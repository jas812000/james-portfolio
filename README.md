# James Stevens — Software Engineering Portfolio

A React portfolio showcasing software engineering projects built with Java, C#/.NET, Python, and frontend technologies.

## Technology

React, JavaScript, Vite, CSS, and Cloudflare.

## Projects

- Accounting Calculators
- Art Inventory & Transaction Management System
- Paws & Reservations
- Reservation Management System
- Home Services Quote Calculator
- Learn English Together

## Local Development

Install dependencies: `npm install`

Start the development server: `npm run dev`

Create a production build: `npm run build`
